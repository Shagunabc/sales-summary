# Task 7 – Sales Summary using SQLite and Python

## Description
This task demonstrates how to use SQL within Python to:
- Connect to a SQLite database
- Perform basic queries (SUM, GROUP BY)
- Load results into pandas
- Visualize the summary using matplotlib

## Tools Used
- Python
- sqlite3
- pandas
- matplotlib

## Output
- Printed summary of quantity sold and revenue per product
- Bar chart showing revenue by product
